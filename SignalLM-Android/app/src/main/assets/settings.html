Android Runtime

Hybrid uses the PC server first and can use the phone as a fallback or parallel helper through the native Android bridge. It does not combine PC and phone VRAM into one model.

Fallback keeps the PC primary. Race starts both runtimes and uses whichever completes first.

Silent Helper

Enable silent context helper

Before the model runs, the app searches selected workspace files and sends compact relevant snippets instead of dumping the whole folder.

Smart snippets usually lowers prompt size and KV-cache pressure. Full selected files is better when a small exact file must be rewritten.
