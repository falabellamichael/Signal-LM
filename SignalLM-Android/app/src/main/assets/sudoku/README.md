# Sudoku Game

A complete, organized Sudoku game with separate HTML, CSS, and JavaScript files.

## Features

- **Three difficulty levels**: Easy, Medium, Hard
- **Move counter** to track your progress
- **Timer** to challenge yourself
- **Hint system** for when you're stuck
- **Error checking** with visual feedback
- **Keyboard navigation** using arrow keys and number pad
- **Responsive design** that works on mobile devices

## Files

| File | Description | Size |
|------|-------------|------|
| `sudoku.html` | Main HTML structure | 2.3KB |
| `sudoku.css` | All styling and animations | 4.7KB |
| `sudoku.js` | Game logic and functionality | 7.7KB |

## Running the Game

Simply open `sudoku.html` in a web browser. No build process required!

## How to Play

1. Click on an empty cell to select it (it will highlight)
2. Type numbers 1-9 using your keyboard or number pad
3. Use arrow keys to navigate between cells
4. Press Backspace/Delete to clear a cell
5. Click "Check" to see if you have any errors
6. Click "Hint" for a suggested move

## Difficulty Settings

- **Easy**: 30 rows × 20 columns, ~10 empty cells removed
- **Medium**: 40 rows × 30 columns, ~20 empty cells removed  
- **Hard**: 50 rows × 40 columns, ~30 empty cells removed

## Controls

| Key | Action |
|-----|--------|
| 1-9 | Enter numbers |
| Arrow keys | Navigate between cells |
